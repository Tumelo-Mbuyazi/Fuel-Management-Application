## 📱 About The Project

The **Car Fuel Management Application** is a Java-based system designed to help customers purchase fuel using a flexible repayment and discount model.

The system validates users and vehicles, calculates fuel quotations, manages repayments, and rewards loyal customers with long-term fuel discounts.

This project combines:

- 🚗 Vehicle management
- ⛽ Fuel quotation systems
- 💳 Electronic payments
- 📊 Customer reward tracking
- 🔐 South African ID & vehicle validation
- 📁 Java File Handling
- 🧠 Business logic implementation

---

# ✨ Main Features

## 👤 User Registration
- Register personal details
- South African ID verification
- Vehicle registration validation
- Upload vehicle image

## 🚘 Vehicle Management
- Select vehicle model
- Fuel tank capacity generation
- Full tank fuel calculation
- Roadworthy verification

## 💰 Fuel Purchase System
- Fuel quotation generation
- Flexible repayment dates
- Discount calculations
- Monthly fuel purchases

## 🎯 Customer Rewards
- Consistent customer discounts
- Long-term repayment reductions
- Loyalty reward system
- Automatic percentage calculations

## 💳 Payment Integration
- Debit Orders
- Google Pay
- Card Payments
- Electronic payment support
